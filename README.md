# 문자전달 (서브폰 문자 → 메인폰 문자)

서브폰(안드로이드)에 오는 **모든 문자(SMS·장문 LMS·MMS)** 를 메인폰 번호로 **문자로 다시 보낸다.**

```
[폰2 헬로모바일/SIM1] 15881234 11/24 14:03
[Web발신] 인증번호 123456 ...
```

## 동작 방식

| 문자 종류 | 받는 방법 |
|---|---|
| SMS (단문) | `SMS_RECEIVED` 브로드캐스트 → 바로 발송 |
| LMS/MMS (장문·사진) | 한국은 장문이 MMS로 옴. 도착 알림(WAP Push) 수신 → 기본 문자앱이 다운로드를 마치면 문자 DB에서 읽어 전송. 15분마다 한 번 더 확인 |
| 발송 SIM | 문자를 받은 그 SIM으로 발송 (듀얼심이면 SIM별로 구분) |
| 발송 실패 | 신호 없음 등으로 실패하면 2·4·8·16·32분 뒤 재시도 (최대 5회) |
| 길이 | 문자 2건(134자) 이내면 원문 그대로. 넘으면 **핵심 줄만 요약해서 최대 3건**으로 보냄 (아래 참고). 요약을 끄면 최대 10건까지 원문 |
| 이미지 | 보내지 않음 (MMS 발송 요금 방지). 이미지와 함께 온 문구는 텍스트로 전달하고 "이미지 n개" 표시 |
| 루프 방지 | 메인폰 번호에서 온 문자는 다시 보내지 않음 |

- 앱 안의 기록에는 발신번호와 결과만 남기고, 본문은 저장하지 않음
- 설치하기 전에 받은 MMS는 보내지 않음 (첫 실행 시점이 기준)

## 긴 문자 요약 규칙

사은품·기프티콘 안내처럼 긴 문자는 아래 순서로 중요한 줄만 골라 문자 3건(201자) 안에 맞춘다.

| 우선순위 | 남기는 줄 |
|---|---|
| 1 | 쿠폰번호·핀번호·인증번호·교환권번호, 코드처럼 생긴 문자열(영숫자 8자 이상), 링크 |
| 2 | 상품명·유효기간·금액·포인트·요금 |
| 3 | "도착/지급/발송/당첨" 같은 안내 제목, 보낸 회사 이름 |
| 버림 | `[주의사항]`·`[제한사항]`·`※ 유의사항` 구간, 약관·환불·고객센터·문의·수신거부 줄 |

**1·2순위 줄이 하나도 없으면** (점검 공지 등 규칙에 안 걸리는 문자) 요약하지 않고 **앞에서부터 들어가는 만큼** 보내고 끝에 `(앞부분·원문 N자)`를 붙인다.

예시 (유모바일 쿠팡 교환권 815자 → 157자, 문자 3건):

```
[탭S11/SIM1 LMS] 15441234 11/24 17:10
유플러스 유모바일입니다.
이츠 요금제를 이용하시는 고객님께 드리는 기본 혜택(쿠팡이츠 5천원 기프트카드)이 도착했…
상품명: 쿠팡 캐시 교환권 5천원권
쿠폰번호: 69QFW2HZNP3E8JJ4
유효기간: 2026.09.16 ~ 2026.11.15
(요약·원문 815자·이미지 1개)
```

규칙은 `Summarizer.kt`, 테스트는 `SummarizerTest.kt`. 요약이 이상하게 나오는 문자가 있으면 테스트 케이스로 추가해서 고치면 됨.

## 1. APK 받기

- 이 레포의 **Actions → Build APK → 최신 실행 → Artifacts → `sms-forwarder-apk`** 에서 다운로드 (zip 파일 안에 apk 있음)
- `main` 브랜치에 머지하면 **Releases**에도 apk가 올라감 → 폰 브라우저로 바로 받으면 됨

## 2. 서브폰에 설치 (삼성 기준)

| 단계 | 할 일 |
|---|---|
| ① 자동 차단 끄기 | 설정 → 보안 및 개인정보 보호 → **자동 차단** 끄기 (설치 후 다시 켜도 됨) |
| ② 설치 | 내 파일에서 apk 실행 → "출처를 알 수 없는 앱" 허용 → 설치. Play 프로텍트 경고가 뜨면 "무시하고 설치" |
| ③ 권한 | 앱에서 **[1. 문자 권한 허용]** 누르기 (수신·읽기·발송). 막히면 **[앱 정보 열기] → ⋮ → 제한된 설정 허용** 후 다시 1번 |
| ④ 배터리 | **[2. 배터리 최적화 예외]** 누르기 + 설정 → 배터리 → 백그라운드 사용 제한 → **절전 예외 앱**에 추가 |
| ⑤ 설정 | 기기 이름, 받을 번호(메인폰) 입력 → **[저장]** → **[테스트 전송]** |

④번을 빼먹으면 삼성이 앱을 "잠자는 앱"으로 바꿔서 문자가 와도 앱이 안 깨어남.

## 업데이트 설치용 서명키

GitHub Secrets에 아래 2개가 있으면 매 빌드가 같은 키로 서명돼서 **기존 앱 위에 덮어쓰기 설치**가 됨 (설정 유지).
없으면 임시 키로 서명 → 업데이트마다 삭제 후 재설치 필요.

| Secret 이름 | 값 |
|---|---|
| `SIGNING_KEYSTORE_B64` | 키스토어(.jks, PKCS12, alias `smsfwd`)의 base64 |
| `SIGNING_PASSWORD` | 키스토어·키 비밀번호 |

- 키스토어 파일·비밀번호는 레포에 올리지 말 것 (.gitignore 처리됨)
- **키를 잃어버리면 다시 삭제 후 재설치**해야 하므로 비밀번호 관리자 등에 백업해 둘 것

## 리스크

- **문자 요금**: 전달 1건 = 서브폰 회선에서 문자 1건 이상 발송. 요금제 기본제공 문자를 다 쓰면 건당 과금됨 → 각 회선 요금제의 문자 제공량 확인. 장문 1통이 분할 문자 여러 건(최대 10건)이 될 수 있음
- **인증번호가 문자로 한 번 더 오감.** 메인폰 분실 시 노출 범위가 늘어남 → 두 폰 다 화면 잠금 필수
- 받을 번호는 앱 안에만 저장됨. 레포나 이슈에 번호를 적지 말 것
- 짧은 시간에 문자를 많이 보내면 통신사 스팸 차단에 걸릴 수 있음 (월 10건 수준이면 문제없을 것으로 예상, 확인된 사실은 아님)
- 유심이 꽂혀 있고 전원이 켜져 있으며 신호가 잡히는 기기에서만 동작
- 제조사 문자앱의 MMS 자동 다운로드가 꺼져 있으면 장문이 늦게 오거나 안 옴 → 문자앱 설정에서 **MMS 자동 다운로드** 켜기

## 빌드 (로컬)

Android SDK가 있는 PC에서 `./gradlew assembleRelease` 실행. 결과물은 `app/build/outputs/apk/release/`에 생김.
